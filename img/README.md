# Ảnh của trang chủ storknstork.com

Hiện tại toàn bộ là ảnh **placeholder** (SVG, có chữ "placeholder"). Thay bằng ảnh thật theo bảng dưới.

Cách thay (dễ nhất): làm file PNG **cùng tên** (vd `mascot.png`), bỏ vào thư mục `img/`, rồi mở `index.html`
và đổi đuôi `.svg` → `.png` ở đúng dòng tương ứng (tìm tên file, ví dụ `img/mascot.svg`).
Nhớ upload cả ảnh mới lên GitHub.

| File hiện tại | Thay bằng | Kích thước đề xuất | Ghi chú |
|---|---|---|---|
| `mascot.svg` | `mascot.png` | cao ~800px, nền trong | Nhân vật cây đứng giữa hero |
| `logo.svg` | `logo.png` | rộng ~1000px, nền trong | Logo game "Tinker Survival IO" |
| `shot-1.svg` … `shot-5.svg` | `shot-1.png` … `shot-5.png` | 1080×2340 (dọc) | Ảnh chụp màn hình game; dưới ~400KB/ảnh nếu được (dùng .webp/.jpg nén) |
| `favicon.svg` | `favicon.png` | 512×512 | Icon app, hiện ở tab trình duyệt |
| `og-image.svg` | `og-image.png` | 1024×500 | Feature graphic; hiện khi chia sẻ link (Facebook/Zalo/Discord cần PNG/JPG, không đọc SVG) |
| `studio.svg` | `studio.png` | 240×240, nền trong | Linh vật/logo studio (con cò) ở mục About |
